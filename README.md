## ⚡ Cara Menjalankan Secara Lokal (Local Development)

Kamu bisa langsung membuka file `index.html` di browser apa pun tanpa perlu instalasi rumit:

1. **Clone repository ini:**
   ```bash
   git clone https://github.com/<your-username>/<repository-name>.git
   cd <repository-name>
   ```

2. **Jalankan langsung:**
   - Cukup **double-click** file `index.html`, ATAU
   - Gunakan extension **Live Server** di VS Code (`Right Click -> Open with Live Server`).

---

## 🚀 Cara Mengaktifkan GitHub Pages (Gratis)

1. Masuk ke tab **Settings** pada repository ini di GitHub.
2. Pada menu sebelah kiri, pilih **Pages** (di bawah bagian *Code and automation*).
3. Di bagian **Build and deployment > Source**, pilih **Deploy from a branch**.
4. Di bagian **Branch**, pilih branch `main` (atau `master`) dan folder `/ (root)`, lalu klik **Save**.
5. Tunggu 1–2 menit, refresh halaman. Link website portfolio kamu akan muncul:
   `https://<your-username>.github.io/<repository-name>/`!
