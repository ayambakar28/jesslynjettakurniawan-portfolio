## 💡 Cara Mengganti Foto dengan Foto Asli Kamu:

1. Siapkan foto atau screenshot proyek asli kamu.
2. Ubah nama file foto kamu sesuai dengan tabel di atas (contoh: pasfoto kamu dinamai **`profile.jpg`**).
3. Masukkan / timpa (*replace*) file tersebut ke dalam folder **`assets/images/`**.
4. Refresh browser website kamu, foto otomatis berubah!
